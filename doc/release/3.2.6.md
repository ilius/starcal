## Changes since 3.2.5

- Fix events disappearing from search results: `EventSearchTree` now recomputes
  a node's min/max time after deletion, so whole subtrees are no longer pruned
  and valid events stay findable (e.g. after moving an event to trash)

  - Add tests for the delete path

- Event library bug fixes:
  - `EventGroup.save` now respects the global `allReadOnly` setting when checking
    whether a group is read-only
  - Add `EventContainer.__bool__` so disabled containers (e.g. trash) are Falsy
  - Fix the "conflict with" rule name in `WeekMonthEventRule` (non-critical bug)

- Fix typos in Persian translation (fa.po)

  - Use Persian "yeh" instead of Arabic "yeh" in "Zooming" strings
  - `هنگاه` -> `هنگام`

- Fix typos in README.md and license dialog
- Update `.gitignore` (add `mypy-analyzer.*` and `*-sample.json`)
- `distro/base/install.sh`: clean up all `.mypy_cache` directories, not just the top-level one

**Full Changelog**: https://github.com/ilius/starcal/compare/3.2.5...3.2.6
